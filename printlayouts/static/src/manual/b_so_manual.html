01

系统自动完成（你无需操作）

确认 B 的销售订单后，系统自动：

  1. 在 C（鼎盛）为每个有物料清单（BoM）的成品行 创建生产单（MO）。
  2. 该 MO 自动确认。
  3. 自动生成两张 原材料调拨草稿（B→C）：「送往鼎盛 B→C」＋「收货自惠州誉达 C←B」。
  4. 自动 取消 B 向 C 的冗余成品采购单（约 2 分钟内，由后台定时任务处理）——成品由 C 生产，而非采购。
你会在 C 看到已确认的 MO，在 B/C 看到两张原材料草稿调拨单——都是自动生成的。
02

手动操作步骤

1

原材料发运 B → C

B → C
  1. 【公司 B】库存 → 送往鼎盛 B→C 打开草稿 → 验证（原材料：惠州誉达/Stock → 公司间中转）。
  2. 右上角切换到公司 C → 库存 → 收货自惠州誉达 C←B 打开草稿 → 验证（中转 → 鼎盛/Stock）。
库存B 出库原料库存C 入库原料
2

C 生产（运行 MO）

C
  1. 【公司 C】制造 → 生产订单 打开对应 MO（已"已确认"）。
  2. 检查可用性（预留刚收到的原材料）→ 生产 → 标记完成。扣减原料，成品入 鼎盛/Stock。（允许负库存，时间差不卡单。）
库存扣原材库存成品入库
✔ MO 标记完成后，系统自动生成两张 成品返运草稿（C→B）：「送往惠州誉达 C→B」＋「收货自鼎盛 B←C」。
3

成品返运 C → B

C → B
  1. 【公司 C】库存 → 送往惠州誉达 C→B 打开草稿 → 验证（成品：鼎盛/Stock → 中转）。
  2. 切换到公司 B → 库存 → 收货自鼎盛 B←C 打开草稿 → 验证（中转 → 惠州誉达/Stock）。
库存C 出库成品库存B 入库成品
4

B 向客户发货 ＋ 打印送货单

B → 客户
  1. 【公司 B】销售 → 订单 打开该 SO → 交货（或 库存 → 交货）→ 检查可用性 → 验证（成品 → 客户）。
  2. 打印送货单：在交货单列表勾选（可勾选同一客户的多张交货单，合并成一张送货单）→ 打印 → 送货单。
库存B 出库发货
